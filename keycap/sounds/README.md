# 타건음 넣는 곳

이 폴더에 아래 이름으로 소리 파일을 넣으면, 합성음 대신 그 소리가 재생돼요.
파일이 없으면 자동으로 기존 합성음이 나와요.

| 스위치 | 누를 때 | 뗄 때 |
|---|---|---|
| 적축 (red) | `red_down.mp3` | `red_up.mp3` |
| 갈축 (brown) | `brown_down.mp3` | `brown_up.mp3` |
| 청축 (blue) | `blue_down.mp3` | `blue_up.mp3` |

- 확장자는 `.mp3`, `.wav`, `.ogg`, `.m4a` 중 아무거나 됩니다.
- 같은 소리를 여러 번 녹음했다면 `red_down_2.mp3`, `red_down_3.mp3` … 처럼 번호를 붙이세요 (최대 6개).
  누를 때마다 그중 하나가 무작위로, 음높이를 아주 살짝 바꿔서 재생돼서 더 자연스러워요.
- 녹음 팁: 소리 앞의 무음은 잘라 주세요 (앞이 비어 있으면 누르는 순간과 소리가 어긋나요). 길이는 0.1~0.3초면 충분해요.
- 파일은 웹서버(GitHub Pages나 `python3 -m http.server`)에서 열 때만 불러와져요. 파일을 더블클릭해서 열면 브라우저 보안 때문에 합성음이 나옵니다.
